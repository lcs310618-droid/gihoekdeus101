# 기획듀스 101

링크 하나로 들어가는 피갤 1중대 사이트. 구글 로그인만 있으면 되고 Claude 계정은 필요 없습니다.
운영 설정(요일·마감·카드 수·멤버·계란님 계정)은 전부 사이트 안 관리 탭에서 바꿉니다.

| 파일 | 역할 | 손댈 일 |
| --- | --- | --- |
| `index.html` | 사이트 전체 | 없음 (기능 추가는 Fable) |
| `firebase-config.js` | Firebase 연결 정보 | 처음 한 번 붙여넣기 |
| `firestore.rules` | 데이터 접근 규칙 (익명 보장) | 처음 한 번 붙여넣기, 고칠 것 없음 |

## 처음 한 번 (15분)

### 1. Firebase — 데이터와 로그인 (5분)
1. https://console.firebase.google.com → **프로젝트 추가** → 이름 아무거나 → 애널리틱스는 꺼도 됨 → 만들기
2. 왼쪽 **빌드 → Authentication → 시작하기 → Google → 사용 설정** → 저장
3. 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (Seoul)` → **프로덕션 모드** → 만들기
4. 위쪽 **규칙** 탭 → 내용 전부 지우고 `firestore.rules` 파일 내용을 그대로 붙여넣기 → **게시** (고칠 것 없음)
5. 왼쪽 위 **톱니(프로젝트 설정) → 내 앱 → `</>` 웹** → 닉네임 아무거나 → 앱 등록 → 화면에 나온 코드를 복사 → `firebase-config.js` 파일 내용을 전부 지우고 붙여넣기 (import 줄이 섞여 있어도 됨)

### 2. 사이트 올리기 — GitHub Pages, 무료 (5분)
1. https://github.com 로그인 (없으면 가입 2분) → **New repository** → 이름 `gihoekdeus101` → Public → **Create repository**
2. 화면 가운데 **uploading an existing file** 클릭 → 이 폴더의 파일 전부를 끌어다 놓기 → **Commit changes**
3. 저장소 **Settings → Pages → Branch: `main`** → Save → 1분 뒤 위에 주소가 뜸 (`https://아이디.github.io/gihoekdeus101/`)
4. Firebase 콘솔 → **Authentication → 설정 탭 → 승인된 도메인 → 도메인 추가** → `아이디.github.io` (이걸 빼먹으면 구글 로그인이 거부됩니다)

저장소가 Public이어도 괜찮습니다. `firebase-config.js` 값은 원래 공개되는 정보이고, 보안은 규칙이 맡습니다.

### 3. 사이트 안에서 (2분)
1. 주소를 **계란님이 먼저** 열고 구글 로그인 → **첫 설정** 화면에서 **이 계정으로 등록** → 이 계정이 계란님(작성자를 보는 유일한 계정)이 됩니다.
2. **관리 탭 → 멤버 관리**에서 우재 PD 이메일을 **운영자**로, 팀원 이메일을 **멤버**로 추가.
3. 주소를 디스코드에 공지. 팀원은 그 구글 계정으로 로그인하면 바로 들어옵니다.

팀원에게 한 줄: 카카오톡·인스타 안에서 열면 구글 로그인이 막히니 Chrome/Safari로 열기.

## 운영 중에 바꾸기
전부 관리 탭입니다. 월드컵 요일, 마감 시각, 회차 목표 카드 수, 1인 상한, 계란님 카드 수, 둘 다 통과 횟수, 상세 공개 라운드, 배틀 시안 수, 일정 문구, 이번 회차 단계 강제, 멤버 추가·운영자 지정, 계란님 계정 바꾸기.

## 기능 추가 (Fable)
- Claude에 GitHub를 연결해 두면: "gihoekdeus101 저장소 index.html에 ~ 추가해서 main에 올려줘" → 1분 뒤 사이트에 반영됩니다. 코드 안내(`CLAUDE.md`)가 저장소에 있어 어떤 대화에서든 구조를 읽고 고칩니다.
- 연결 없이도: `index.html`을 Fable에게 첨부해 고쳐 달라고 한 뒤, 받은 파일을 GitHub에서 **Add file → Upload files**로 덮어쓰면 됩니다.
- `firestore.rules`를 바꾼 경우에만 Firebase 콘솔 규칙 탭에 다시 붙여넣고 게시합니다.
- 큰 변경은 "브랜치로 올려줘"라고 하면 사이트에 반영되기 전에 확인할 수 있습니다.

## 권한
| 권한 | 누구 | 할 수 있는 것 |
| --- | --- | --- |
| 계란님 | 첫 설정에서 등록한 계정 | 전부 + 카드·시안·코멘트 작성자 열람(🔒) + 선정 |
| 운영자 | 멤버 관리에서 지정 | 설정, 단계 강제, 배틀 관리, 멤버 추가 |
| 멤버 | 나머지 | 카드·시안 올리기, 월드컵, 코멘트 |

작성자 정보는 `authors/{uid}`에 저장되고 Firestore 규칙이 본인과 계란님 외의 읽기를 막습니다. 운영자도 못 읽습니다.

## 비용
Firebase Spark(무료) 한도 안입니다 (하루 읽기 5만, 쓰기 2만). 8명이 하루 종일 써도 수천 건입니다. GitHub Pages도 무료, 카드 등록 없음.

## 막히면
- "규칙이 아직 없습니다": 1-4 단계(규칙 게시)를 확인.
- "설정이 아직 없습니다": 1-5 단계(`firebase-config.js`)를 확인.
- 로그인 창이 뜨자마자 거부: 2-4 단계(승인된 도메인)를 확인.
- 계란님이 아닌 계정이 먼저 '첫 설정'을 눌러버렸다면: Firebase 콘솔 → Firestore → `settings` → `main` 문서 삭제 → 계란님이 다시 로그인해서 등록. (그래서 주소는 계란님이 등록한 뒤에 공지합니다)
- 그래도 안 되면 그 화면을 찍어 Fable에게 보내기.
